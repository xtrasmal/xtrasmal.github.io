A faithful port of the Horizon theme, rebuilt from the official horizon-theme-vscode palette — hand-built, fully-scoped themes for Helix and Zed, a native iTerm2 scheme, and 30+ generated terminal formats. The Zed themes are checked key-by-key against Zed’s published theme schema — see 05.

Syntax — the scopes Zed actually emits

Zed resolves a tree-sitter capture right-to-left through its fallback chain, so function.method only lands on function if the dotted scope isn’t defined. HorizonCode defines the dotted scopes, so methods, builtins, macros and mutable bindings stay distinguishable instead of collapsing. Orange marks scopes the official Zed themes leave undefined.

LSP semantic tokens are covered too — with "semantic_tokens": "combined" Zed layers token types over tree-sitter, looking for styles named type.class, enumMember, typeParameter, macro, parameter, deprecated and friends. All of them resolve. One gap, stated plainly: the per-mode vim keys added to Zed’s colour struct aren’t in the published schema yet and their JSON spelling isn’t documented, so they’re deliberately left out rather than guessed — vim mode still reads correctly from the status colours.
